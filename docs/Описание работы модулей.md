## Описание отдельных файлов и их назначение

### .gitignore

Файл, содержащий файлы, которые не должны быть проигнорированы и не добавлены в удаленный репозиторий

### README.md

Краткое описание процесса сборки и запуска программы, также форматы некоторых файлов json

### requirements.txt

Модули, необходимые для работы программы. Без их установки невозможна работа программы. Они могут быть установлены вручную либо с помощью команды:     

```
pip install -r requirements.txt
```

### server.py

Основной файл программы. Содержит функцию main, которая запускает всю программу. Получает запрос от фронта с данными в виде json структуры, переадрессует их на [обработчик запросов](..\scripts\request_handler.py) Для запуска используется следующая команда: <br>

```
uvicorn server:app --reload --port 8083
```

### папка configs

Папка "configs" содержит файлы необходимые для тех или иных конфигураций программы до ее запуска. Например, создание базы данных, получение сведений о оборудовании и т.п.

### configs/db_config.sql

Файл *db_config.sql*  используется для создания базы данных, пользователя и таблиц, необходимых для использования в программе (таблицы используется не все, так как разработка не завершена. При разработке структуры таблиц, предполагалоь хранение карт нормативов в таблицах, однако из-за недостатка времени их хранение было принято вести в файлах с расширением json. В перспективе нужно их перенести в БД, чтобы все данные, что нужно хранить были в одном месте). Скрипт можно сразу копировать и запускать.


### configs/equipment_config.json

Хранит данные по уже добавленным аппаратурам (в перспективе их добавление будет реализовано через редактор). Эти данные отсылаются на фронт для отображении в редакторе

### папка diagrams

Папка с диаграммами, например, диаграмма [KUTC.png](../diagrams\KUTC.png) содержит информацию о логике работы прохождения нормативов в основной части программы. Данная диаграмма используется в [README.md](..\README.md)

### папка docs

Содержит файлы с описаниями протоколов и других элементов программы. Например, BACK_FRONT_PROTOCOL содержит (старую версию, руками просто брали и качали себе для удобства у ребят с фронта, надо обновить с вики) протокол взаимодейтсвия бекенда с фронтом. А данный файл, содержит описание файловой структуры проекта и краткое описание назначения и внутреннего содержания


### папка equipment_configs

Содержит файлы с описанием элементов аппаратуры

### папка film_norm 

Карты для норматива по фильму для аппаратуры П-302-О

### папка init_jsons

Файлы упрощающие работу с элементами аппаратуры. Например, id2type_P302O сопоставляет типы элементов с их id2type_P302O

### папки norm_1, norm_2

Папки с двумя нормативами по аппаратуре П-302-О

### папка normative_configs

Файлы с сопоставлением id норматива и карты для него

### папка normatives 

Папки с нормативами по каждой из добавленных аппаратур

### папка scripts

Попытка структурировать файлы в проекте. Тут лежат большинство скриптов

### scripts/authorization.py

Функции, необходимые для авторизации на сайте

### scripts/db_fast_scripts.py

Часто используемые функции, связанные с БД. Например, часто нужно было получать id шага через функцию get_step_id, она была вынесена в отдельую функцию и в отдельный файл, так как используется во многих местах программы

### scripts/dbconnection.py

Класс для подключения к базе данных через шаблон синглетон. Также содержит некоторые другие функции для работы БД, например, интрефейс для получения таких запросов, как "WHERE ...", "DELETE ... WHERE ..."

### scripts/editor_scripts.py

API для общения с фронтом. Например, отправка списка существующих аппаратур, элементов и нормативов

### scripts/elements_handler.py

Функции для добавления новых элементов или их редактирования

### scripts/equipment_creator.py

Функции для добавления новой аппаратуры или ее редактирования

### scripts/exercise.py

Функции для работы с нормативами

### scripts/image_operations.py

Функции для добавления новой аппаратуры или ее редактирования

### папка src 

Еще одна попытка лучшего структурирования файлов (не вышло внедрить, но очень хочется)
